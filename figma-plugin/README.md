# Figma plugin – NurseShift návrh obrazovek
1. Ve Figma Desktop: Plugins → Development → Import plugin from manifest… → vyber `manifest.json` v této složce.
2. Otevři libovolný Design soubor a spusť Plugins → Development → NurseShift návrh obrazovek.
3. Na plátně vzniknou 3 obrazovky pod sebou ve vzhledu aplikace (plánovací matice, pohled sestry, nastavení oddělení a uživatelé). Při opakovaném spuštění je před tím smaž (jinak se zdvojí).
