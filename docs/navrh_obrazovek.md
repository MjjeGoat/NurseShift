# Návrh obrazovek (wireframy)

## 1. Přihlášení
Tlačítko „Přihlásit přes Microsoft“ (Entra ID). V dev režimu výběr testovacího účtu.

## 2. Měsíční rozpis (matice směn) – Vrchní sestra / Admin
```
[< říjen]  LISTOPAD 2026  [prosinec >]   Stav: [koncept v]   [Uložit]
+------------------+----+----+----+----+-----
| Sestra / Úvazek  | 1  | 2  | 3  | 4  | ...
+------------------+----+----+----+----+-----
| Nováková  1.0    | D  | D  | V  | N  |
| Černá     1.0    | D  | D  | V  | V  |
+------------------+----+----+----+----+-----
| Obsazenost D/N   | 3/2| 3/2| ...
```
Klik na buňku přepíná D / N / DOV / V. Řádek obsazenosti zvýrazní nedostatečné počty.

## 3. Pohled sestry
Stejná matice jen pro čtení, vlastní řádek zvýrazněn.

## 4. Správa uživatelů (Admin)
Tabulka (jméno, e-mail, role, úvazek, aktivní) + formulář přidat/upravit/smazat.

## 5. Nastavení oddělení (Admin / Vrchní sestra)
Délka směny, min. obsazenost den/noc, týdenní fond hodin, pravidla (noc→den, max. po sobě jdoucích směn).
